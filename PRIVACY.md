# Privacy Policy for Focus Tracker

Last updated: May 26, 2026

Focus Tracker is a Chrome extension for blocking distracting websites, tracking website usage, managing temporary extra time, and running focus sessions.

This policy explains what data the extension handles, how it is used, and how it is stored.

## Data The Extension Handles

Focus Tracker handles the following data to provide its core features:

- Website rules: domains added by the user, schedules, daily allowances, exceptions, block modes, visual filter settings, warning settings, and related preferences.
- Web browsing activity: the active HTTP/HTTPS domain, usage duration, usage date, hourly usage summaries, and blocked/allowed status needed for blocking and analytics.
- Authentication information: the optional 4-digit PIN used to protect extra time.
- Focus session data: focus duration, focus mode, whitelist domains, session status, and focus session history.
- Temporary extra-time data: added minutes, remaining extra time, and revoke state for configured websites.

Focus Tracker does not collect health information, financial information, location, personal communications, website page content, form contents, mouse movement, scroll position, or keystroke logs.

## How The Data Is Used

The extension uses this data only to provide its user-facing features:

- Block or allow websites according to the user's rules.
- Track time spent on websites and show usage analytics.
- Manage daily allowances and temporary extra time.
- Validate the optional PIN for extra time.
- Start, stop, and summarize Pomodoro-style focus sessions.
- Apply optional grayscale, night light, and limit warning overlays.
- Keep blocking rules current across open tabs.

## Storage And Transfer

Focus Tracker stores extension data locally using Chrome extension storage on the user's device.

The extension does not send user data to a developer server, analytics service, advertising network, or third-party data broker.

The extension does not sell user data.

The extension does not use user data for advertising, creditworthiness, lending, or any purpose unrelated to its single purpose of website blocking, usage tracking, and focus support.

## Data Retention

Website rules, settings, PIN settings, and focus preferences are kept until the user changes them, clears them, or removes the extension.

Daily website usage history is retained for the current day plus up to 30 completed days.

Focus session history is retained for up to 90 days or 500 session records, whichever limit is reached first.

Removing the extension from Chrome removes its locally stored extension data from that Chrome profile.

## Website Content

Focus Tracker does not read, store, transmit, or sell the text, images, videos, messages, forms, or other content of webpages.

The extension may inject local packaged scripts or styles into tabs only to show the blocking overlay, show limit warnings, apply visual filters, or clean up those extension UI elements. These scripts are not used to scrape website content.

## Chrome Web Store Limited Use Disclosure

Focus Tracker's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

The extension uses Chrome permissions only to provide or improve the user-facing features described in the extension listing and interface. User data is not transferred except as necessary to provide those features, comply with applicable law, or protect against security abuse. User data is not used for personalized advertising, retargeting, interest-based advertising, creditworthiness, or lending purposes.
